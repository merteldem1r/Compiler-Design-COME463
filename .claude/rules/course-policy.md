# Course policy (academic integrity)

The course allows AI tools, but under conditions that bind the agent too.

## The student must own every line
- The professor questions students **live** about their code. Prefer simple code that mirrors the lecture examples over clever or "industrial" solutions.
- Never add code the student hasn't seen explained (see `workflow.md`).

## Log AI usage
- Every report needs an AI section: tools used, **2–3 prompts verbatim**, and **what the AI got wrong and how it was fixed**.
- Record these in `docs/AI_USAGE.md` as they happen. Write down AI mistakes honestly; they are required report content, not something to hide.

## Handwritten, individual parts (e.g. P1 Part A)
- Act as a **tutor**: explain the method, give *similar* practice problems, check the student's own attempts, and point out errors.
- Don't produce final answers to the graded questions for copying.

## Read-only material
- `projects/*/directives/`: the professor's assignment text, kept verbatim. If the professor updates it, replace the whole file from the source; never edit it in place.
- `docs/lectures-notes/`: course material.

## Privacy
- The repository stays **private** while the course runs (posting solutions is forbidden). Never create a public remote or publish solution content.
